# ¿Qué mineral soy?

Extrae todo el ZIP y abre `index.html` en un navegador. El juego funciona sin conexión y también desde un servidor web estático.

Cada partida selecciona al azar cinco muestras distintas de las 16 del prototipo, incluida la obsidiana, que es una roca volcánica. Cada pregunta tiene una fotografía, tres pistas y tres respuestas posibles. El marcador se reinicia al pulsar «Nueva partida».

`creditos.html` recoge la autoría, la licencia y la ficha original de cada fotografía.
